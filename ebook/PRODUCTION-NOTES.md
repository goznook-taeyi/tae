> ⚠️ 이 파일은 원고에 포함하지 않는다. 판매 페이지·최종 PDF에서 제외할 것.

## 1. 익명화 검수 (출간 전 필수)

원고의 사례는 실제 클라이언트 자료에서 왔다. 최종 PDF 빌드 전에 아래를 다시 확인:

- 병원 실명·시술명·지역이 조합되어 특정 가능한 서술이 없는지 (예: "입술 시술로 유명" + "강남" 조합 주의 — 현재 원고는 지역명을 뺐음)
- 기획안 인용 문구가 실제 업로드된 영상의 자막과 축자 일치하지 않는지 (일치하면 역추적 가능 — 표현을 바꿀 것)
- 프리랜서·직원 실명 없음 (확인됨)
- 강의 기관은 "국제공항을 운영하는 공기업"까지만 (계약상 실명 사용 가능 여부 확인 후 결정)

## 3. 판매 전략 (72시간 계획과의 연결)

- **가격**: 니치 실무서 + 검증 강점 → 2.9만~4.9만 원대 권장 (일반 전자책 1만 원대와 차별화). 병원 마케터·제작사 대상이므로 가격 저항 낮음.
- **채널**: 크몽(검색 유입·리뷰) + 래피드(Latpeed, 저수수료·직판) 병행 — 16장 원리 그대로.
- **런칭 순서**: ① 목차+1장 무료 샘플 PDF → ② 크몽 등록 → ③ 래피드 판매 페이지 → ④ 책 목차에서 숏폼 대본 10개 추출해 홍보 (예: "검수 체크리스트 1번이 생긴 사고", "전후사진 불법이라는 말, 반은 틀렸습니다")
- **리드 연결**: 책 말미에 강의·제작 문의 경로 추가 (최종본에서) — 책의 진짜 수익은 리드.

# Project Guidance

## Skills

This repo vendors 25 project-level skills in `.claude/skills/` (see `.claude/skills/README.md` for the full catalog and sources). Use them proactively — don't wait to be asked:

- Starting any multi-step, tool-using task → invoke `task-observer` first.
- New feature or vague idea → `brainstorming`, then `writing-plans`, then `executing-plans`.
- Writing or changing code → `test-driven-development`; before saying "done" → `verification-before-completion`.
- Any bug, test failure, or unexpected behavior → `systematic-debugging` before attempting fixes.
- Any UI/frontend work (design, review, polish, animation, accessibility) → `impeccable`.
- Unfamiliar code → `learn-codebase` or `pathfinder`; confusing code → `what-the`.
- Wrapping up a branch → `finishing-a-development-branch`.
- A capability is missing → `find-skills` to search the skills ecosystem.

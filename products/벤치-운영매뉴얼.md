> 벤치-머신-설계.md의 실행 도구 모음. 프리 이탈 대비 지금 바로 쓸 것.
> 원칙: 프리 1명당 대표가 손대는 횟수를 줄이는 게 곧 확장. (span 6명 → 12명 → 팟 구조 20명+)

## 0. 관리 범위(span of control) 원칙
- **지금(수동)**: 혼자 5~6명 천장.
- **머신 적용**: 혼자 10~12명(병원 ~20곳).
- **30곳+**: A급을 **리드**로 승격 → 팟(4~5명)당 리드 1명 → 대표는 리드만 관리(2층).
- 별도 천장: **촬영은 대표 몸** → 병원 20곳 넘어가면 배치촬영 효율화/촬영 위임 필요(추후).

## 1. 표준 편집 테스트 (채용 = 이 한 편으로 판별)
지원자에게 **원본 촬영본 1개 + 기획 뼈대(§3 전달양식)**를 주고 40초 숏폼 1편 제작 요청.
평가 6항목(각 통과/미달):
1. 자막 3종이 음소거로 구분되는가 (규격 이해)
2. 훅이 실제 클라이맥스 발언인가 (낚시 아님)
3. 마이크로세그먼트·침묵·"음…" 제거됐는가 (리듬)
4. 1080p·30fps·9:16·하단 세이프존 준수
5. 파일 네이밍·넘버링 규칙 준수 (핸드오프 적합성)
6. 마감 시간 준수
→ 6/6 = A후보, 4~5 = B, 3 이하 = C 또는 탈락.

## 2. 등급 루브릭 (A / B / C)

| | A급 | B급 | C급 |
|---|---|---|---|
| 실력 | 규격 완벽 + 리듬감 + 컴플라이언스 감각 | 규격 준수, 표준 숏폼 안정 | 기본 편집 가능, 규격·리듬 약함 |
| 배정 | 난이도 높은 병원 · **롱폼** | 표준 숏폼 병원 2곳 | 단순 편집 · 1곳 |
| 검수 강도 | 스팟체크 | 정기 검수 | 전건 검수 |
| 단가 | 프리미엄 + 롱폼수당 | 표준 | 기본 |
| 성장 | **→ 리드 승격 트랙** | → A 승급 | → B 승급 |

> "못하는 프리는 병원 1곳" — 이미 하던 걸 등급으로 명시화한 것.

## 3. 온보딩 체크리스트 (목표: 문서 5분 + 복제 1회)
- [ ] 제작 SOP 정독
- [ ] 드라이브 권한 + 병원 폴더 구조(원본/클린본/완성본/수정본)
- [ ] 캡컷 팀 템플릿 복제 1회
- [ ] 대시보드 접속 + 배정·마감 확인
- [ ] 표준 편집 테스트 1편 → 등급 판정
- [ ] 대표와 검수 1회 동행 (규격을 실제 판정으로 체화)
- [ ] 첫 배정: 소량(1곳)부터 → 안정되면 증량

## 4. 채용 공고 템플릿
> [씨사일] 병원 숏폼 편집 프리랜서 상시 모집
> - 안정적 정기 물량(월정액 병원 기반) · 명확한 등급·단가 사다리 · 잘하면 리드 승격
> - 제작 SOP·캡컷 템플릿·검수 기준 전부 제공 → 추측 없이 작업
> - 지원 = 표준 편집 테스트 1편 (원본·기획 제공)
> 소스: 외주나라 · DOF LOOK · 편집 커뮤니티 + (추후) 교육 수료생 스카웃

## 5. 단가·인센티브 사다리 (숫자는 저자 확정 ❓)
- C 편당 [기본] → B [표준] → A [프리미엄 + 롱폼수당] → 리드 [팟 관리수당].

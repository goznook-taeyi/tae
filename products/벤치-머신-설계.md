# 벤치 머신 설계 — 1인 PD → 시스템 원청(元請) v0.1

> 목적: "프리랜서 부족"(capacity 병목)을 **채용·훈련·품질관리를 시스템화한 벤치**로 해체.
> 북극성: 시스템(SOP)을 **밖으로 팔지 않고**(경쟁자 X) **안으로 겨눠**(내 밑에서 일하는 벤치) 밥그릇을 키운다.
> 현 상태: 프리 5→4명(1 이탈 예정), 인당 병원 2곳, 인당 월 15~40편. 대표 시간 90% 관리.
> 목표 구조: 병원 8곳 → 20~30곳을 벤치가 굴리고, 대표는 영업·품질기준·관계만.

## 1. 원리 — 대표가 하는 일이 바뀐다
| | 지금(1인 PD) | 목표(원청) |
|---|---|---|
| 대표 역할 | 핸드오프·카톡·관리 90% | 영업·품질기준·관계 |
| 제작 | 프리 개별 카톡 배정 | SOP+대시보드가 배정·전달 |
| 확장 한계 | 대표 시간 | 벤치 크기(시스템으로 무한 확장) |

## 2. 벤치 머신 5개 부품

### ① 채용 파이프라인 (공급)
- 소스: 외주나라·DOF LOOK·디하클류 커뮤니티 + **교육 깔때기**(내가 가르친 PD 중 스카웃).
- → 교육이 경쟁자 공장이 아니라 **벤치 오디션**이 됨. (밥그릇 나눠주기 해소)

### ② 테스트 & 온보딩 (표준화)
- 표준 편집 테스트: 기존 완성본 1편을 원본으로 재현 → 실력 즉시 판별.
- SOP 정독 + 캡컷 템플릿 복제 + 검수 1회 동행. (SOP 부록 온보딩 체크리스트 그대로)
- 목표: "문서 5분 + 복제 1회"로 신규 프리 전력화.

### ③ 등급제 (배정 매칭)
- 프리 등급 A/B/C (이미 "못하는 프리는 병원 1곳"으로 암묵 운영 중 → 명시화).
- A=난이도 높은 병원/롱폼, B=표준 숏폼, C=단순 편집·양치기.
- 등급 상승 시 단가·물량↑ → 성장 동기 = 이탈 방지.

### ④ 품질관리 게이트
- 검수 체크리스트(0+8)가 통과 게이트. 등급별 검수 강도 차등(A는 스팟체크, C는 전건).
- 반려는 감정이 아니라 규격 → 프리도 덜 상함.

### ⑤ Capacity 대시보드 (가시성)
- 기존 프리랜서 대시보드에 **프리별 잔여 capacity**(병원 몇 곳 더 가능) 표시.
- → 신규 병원 문의 왔을 때 "받을 수 있나?"를 즉시 판단. 영업과 제작이 분리돼도 안 터짐.

## 3. 이탈 방지 (벤치는 사람이라 샌다)
- 안정적 물량 보장 + 명확한 등급/단가 사다리 + 규격 기반(감정노동 X) 커뮤니케이션.
- 좋은 프리일수록 **시스템 있는 원청**을 선호(그들의 시급을 지켜주니까).

## 4. 산수 — 벤치가 곧 매출 상한
- 프리 1명 = 병원 ~2곳. 병원 20~30곳 목표 → 벤치 ~10~15명 시스템화 필요.
- 직계약(300) 20곳 = 월 6,000 / 30곳 = 월 9,000 → **연 7~10억(대행만).**
- 여기에 롱폼 업셀(병원당 1.8~2배) 얹으면 15억 사정권.
- **즉 15억 = 병원 무한증식이 아니라, 벤치 시스템 × 직계약 × 롱폼업셀.**

## 5. 실행 순서
1. **지금(이탈 1명 계기)**: ②테스트·온보딩 표준화 + ①채용 소스 세팅 → 빠진 자리를 시스템으로 채움(대표 머릿속 의존 끊기).
2. 그다음 ③등급제 + ⑤대시보드 capacity 가시화.
3. 여력 생기면 → 직계약 영업 + 롱폼 업셀(병원-풀패키지-견적서.md) 붙이기.
4. 벤치가 안정되면 → (선택) 프랜차이즈/라이선스로 타 지역 복제.

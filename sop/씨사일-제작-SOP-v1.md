# 씨사일 병원 숏폼 제작 SOP v1

> **이 문서의 목적**: 촬영본 하나가 납품까지 가는 전 과정을, 대표가 매번 카톡으로 챙기지 않아도 같은 품질로 굴러가게 하는 표준 절차서.
> **누가 봐야 하나**: 신규/기존 프리랜서 편집자(온보딩 필수), 검수 담당, 대표/PM.
> **버전 규칙**: 규격 변경 시 v2로 새로 발행(구버전 덮어쓰기 금지). 수정 권한은 규격 관리자(대표) 1인.
> **용도 확장**: 이 문서는 ①프리 온보딩 ②직계약 세일즈 자산 ③병원 내부 미디어 세팅+교육 납품물 ④시스템 라이선스의 공통 본체다.

---

## 0. R&R — 누가 무엇을 책임지나

| 단계 | 담당 | 책임 |
|---|---|---|
| 소싱·솔팅 | 대표/PM | 레퍼런스 수집·선별, 기획 방향 확정 |
| 기획안 작성 | 대표/PM (AI 도우미 보조) | 4열 기획안 시트, 촬영 리스트 |
| 촬영 | PD | 현장 촬영, 3확인 컴플라이언스 |
| **핸드오프** | 대표/PM | 업로드·넘버링·기획포인트 전달 (§3 표준대로) |
| 편집(제작) | 프리랜서 | 규격대로 편집, 마감 준수 |
| 검수 | 내부 | 체크리스트 0+8, 컴플라이언스 |
| 납품 | 대표/PM | 완성본 폴더 업로드 = 납품 확정 |

> 경계가 문서에 있으면 "이건 제 일 아닌데요"가 사라진다.

---

## 1. 파이프라인 5단계 & 완료 기준(Definition of Done)

각 단계는 "끝났다"의 정의가 **물리적 사건**으로 못박혀 있어야 한다.

| 단계 | 하는 일 | 완료 기준(DoD) |
|---|---|---|
| ① 소싱 | 벤치마킹 레퍼런스 수집 | 병원별 후보 목록 확보 |
| ② 솔팅 | 쓸 것만 선별·저장 | 선별본이 지정 폴더에 저장됨 |
| ③ 제작 | 규격대로 편집 | 클린본+완성본 업로드 + 대시보드 '제출됨' |
| ④ 검수 | 규격·톤·컴플라이언스 확인 | 대시보드 '검수완료' |
| ⑤ 납품 | 완성본 클라이언트 폴더 전달 | 완성본 폴더 업로드 = 납품 완료 |

---

## 2. 폴더 구조 & 파일 네이밍 (상태 = 폴더)

- 병원별 폴더 고정 구조: **`원본 / 클린본 / 완성본 / 수정본`**
  - **클린본**(자막·로고 없는 편집본)은 반드시 남긴다 → "자막만 바꿔주세요" 요청이 재편집이 아니라 5분이 된다.
- 드라이브 링크 원본은 **드라이브 인덱스 페이지 한 곳**에만 존재. 다른 문서엔 인덱스를 링크(계정 이전 시 한 곳만 교체).
- 파일 네이밍(권장): `[병원코드]_[YYMMDD]_[기획번호]_[상태].mp4`
  - 예: `WIDER_260721_03_클린.mp4` / `WIDER_260721_03_완성.mp4`

---

## 3. 핸드오프 표준 ★ (대표의 최대 시간먹기 제거)

> 촬영 후 대표가 매번 카톡으로 하던 "업로드→넘버링→기획포인트 설명"을 **고정 양식**으로 대체한다. 프리는 카톡을 기다리지 않고 이 양식만 보면 편집을 시작한다.

**3-1. 업로드 규칙**
- 촬영 당일 원본을 병원 `원본` 폴더에 업로드. 4K 촬영분도 그대로(1080p 편집에서 크롭 여유용).

**3-2. 넘버링 규칙**
- 기획안 시트의 행 번호 = 클립 번호. 촬영본 파일명 앞에 기획번호를 붙여 정렬.
- 한 기획(1편)에 여러 테이크면 `03-1, 03-2…`, 채택 테이크에 ★.

**3-3. 전달 양식 (기획포인트 = 이 표 한 줄로 끝)**

| 항목 | 기입 |
|---|---|
| 기획번호 / 병원 | 03 / 와이더뷰티 |
| 훅 후보 (타임코드) | 03-2 ★ 03:12 "양이 아니라 위치가 정합니다" |
| 메인 뼈대(자막 강조점) | ①실패원인 ②비율 ③순서 ④개인차 — ②③에 강조자막 |
| 반드시 살릴 컷 / 버릴 컷 | 살림: 원장 확신멘트 / 버림: 유행 시술명 실명 언급분 |
| 개인차·컴플라이언스 주의 | 효과 단정 표현 뒤 "개인차" 자막 필수 |
| 마감 | D-2 (YYMMDD) |

> 이 표를 대시보드 배정 메모에 붙인다. 이게 곧 대표 시간 회수의 핵심.

## 4. 편집 규격 (캡컷 팀 템플릿)

프리는 팀 공유 템플릿 프로젝트 `[팀명]_숏폼규격_v1`을 **복제**해서 시작(수정 아님).

**4-1. 자막 3종**

| | 말자막 「중」 | 강조자막 「대」 | 포인트자막 「소」 |
|---|---|---|---|
| 역할 | 정보(대사) | 기억(핵심, 회당 2~3회) | 호감((당황) 등) |
| 크기(화면폭) | 7~8% | 12~15% | 4~5% |
| 색 | 흰+검정테두리 | 포인트 1색(핵심단어만) | 흰/저채도 |
| 위치 | 하단 20%↑ | 중앙 | 자유(세이프존 금지) |
| 움직임 | 없음 | 팝인 0.2초(유일 허용) | 없음 |

**4-2. 오디오 프리셋**: BGM 트랙 더킹 ON, 보이스 트랙 노이즈감소 ON.
**4-3. 내보내기**: 1080p · 30fps · 9:16. 하단 20% 세이프존 비움.
**4-4. 폰트**: 팀 지정 상업용 무료 라이선스 1종 고정.
**4-5. 길이**: 지시 길이는 상한. 기승전결이 더 짧게 완성되면 그게 정답(늘어짐 금지).

## 5. 검수 체크리스트 (0 + 8)

- [ ] **0. 컴플라이언스** — 미동의 얼굴·미승인 구역·미합의 출연 없음 / 의료광고 금지표현(경험담·효과보장·최상급·비교) 없음
- [ ] 1. 이전 프로젝트 템플릿 텍스트 잔재 없음
- [ ] 2. 0.5초 미만 마이크로 세그먼트 없음
- [ ] 3. "음…"·브레스·문장 사이 침묵 제거
- [ ] 4. 훅 = 실제 클라이맥스 발언(낚시 금지)
- [ ] 5. 결론 반복 없음
- [ ] 6. 자막 트랙 1개, 훅/아웃트로에 대사자막 없음
- [ ] 7. 자막 3종이 음소거 재생으로 구분됨
- [ ] 8. 1080p·30fps·9:16, 하단 20% 세이프존 준수

## 6. 피드백 처리 (전달이 아니라 번역)

클라이언트의 감상은 규격 언어로 바꿔서 프리에게 전달한다. 그리고 **일회성 vs 공통규칙**을 분리 — 공통은 즉시 병원별 톤가이드에 편입(다음 달 같은 피드백 소멸).

| 클라이언트 말 | 번역된 지시 |
|---|---|
| "목소리가 묻혀요" | 1번 영상 노이즈제거·보이스 명료도 우선 (+다음 촬영 마이크 위치) |
| "정신없어요" | BGM 제거, 효과음만. 화면 내 동시 움직임 1개 원칙 |
| "도입이 약해요" | 훅 재선정 — 원장 멘트 중 가장 센 것 3초 안 |

---

## 7. 컴플라이언스 게이트 (의료광고)

3중 게이트: **①기획 단계**(금지표현 회피) → **②검수 0번** → **③업로드 전 병원 서면 컨펌**. 애매하면 자율심의기구 사전문의. 심의 접수 책임은 병원 측임을 계약서에 명시.

## A. 확인된 사실 (파일 기반, 2026-07 세션)

- **인물**: 이태이 PD. 사업체 **씨사일 스튜디오 (C-41 Studio, c-41studio.kr)**.
- **주업**: 병원·의원 숏폼(릴스·쇼츠) 제작 대행.
- **클라이언트(관측)**: 아도의원·247외과·리오브 피부과·코비쥬·르디테·장덕한방병원·연세피부사랑·닥터쁘띠·젤성형외과·815클리닉·와이더뷰티 등 (피부·성형·외과·한방).
- **제작 시스템**: 소싱→솔팅→제작→검수→납품 5단계 파이프라인. 기획안 4+1열 구조(장소·질문·훅·메인·CTA). 캡컷 팀 규격 템플릿. 프리랜서 대시보드 자체 구축(freelancer-c41-studio.vercel.app).
- **팀(관측)**: 프리랜서 편집자 — 송주희·김은혜(모모)·이수빈·정주희·양주원.
- **교육 사업**: 인천공항공사(ICN) 숏폼 클래스 교안 제작. 순천 청년활동가학교 '생성형 AI 숏폼' 강의 섭외 진행.
- **AI/자동화**: Claude Code 스킬 25종 도입. 자체 도구 — 숏폼 솔팅기 다운로더, 트렌드 수집 파이프라인, 자막 검수 OCR, 콘텐츠마케터 키티(기획안 자동생성).
- **진행 중**: 전자책 『병원 숏폼으로 먹고삽니다』(제작+AI 파이프라인 합본) v0.3. 스파크플러스 잠실점 입주 검토.

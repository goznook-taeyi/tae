- **본인 시간 배분**: **관리 90% / 제작 10%** — 이미 제작에서 손 뗌.

- **성장 병목(본인 진단)**: ① **와이더뷰티 단가구조** — 거기 묶여 마진·확장 캡. ② **1인 사업가라 프리랜서 부족** → 물량 확장 불가.
- **최근 이탈**: **루센느** — "조회수 잘 나오는 큐레이션 콘텐츠" 하겠다며 이탈. → '문의 전환' 포지션 vs '조회수' 원하는 고객의 미스매치.
- **하기 싫지만 돈 때문에**: **카톡으로 업체 관리**(클라이언트 커뮤니케이션).
- **밤에 잠 못 드는 걱정**: **확장 방향성**.

## F. 성장 축 & 방향 (인터뷰, 2차 보정)
- **제작 : 교육 : 지식상품 목표 비중 = 5 : 2 : 3.** 성장은 "제작 확대 + 교육상품 판매"로 봄.
- **확장 선호 순위 (5→1)**: ⑤대행 시스템 자체 판매 > ④교육 상품화 > ③다점포/프랜차이즈 > ②타 업종 > ①병원 수 늘리기.
  → **'인력 비례 성장(병원 수↑)'을 가장 원치 않고 '레버리지 성장'을 원함.**
- **'시스템을 판다'의 본인 정의**: 전자책·SOP 패키지 아님. → **"병원 내부 미디어 세팅 + 교육"** (병원이 자체적으로 콘텐츠를 굴리도록 세팅해주고 가르치는 것). ⚠️ 대행 매출과 카니발 우려 vs 별도 세그먼트/퍼널 여부는 미결.
- **전자책에 회의적**: "전자책은 수강생에게 하등 도움 안 됨." → 현재 진행 중 전자책의 역할 재검토 필요(상품 X, 리드마그넷/신뢰자산으로 격하 검토).
- **신규 유입**: **인바운드 문의 0.** 자체 획득 채널 없음 → 와이더뷰티 의존이 사실상 전면적.

## ★ 북극성 (핵심 본질) — 모든 결정의 기준

> **본질**: 조회수가 아니라 **문의(환자)를 만드는 콘텐츠**를, **누구나 반복할 수 있는 시스템**으로 만든다.
> **진짜 상품 = '영상'이 아니라 '그 시스템' 자체.** 영상은 시스템이 작동한다는 증거.
> **무게중심 이동**: "우리가 영상 만들어드림"(노동·와이더뷰티 종속) → "문의로 바꾸는 시스템을 설치·운영·교육함"(자산·레버리지).
>
> **근거**: ①배민 커머스+직무교육 콘텐츠 이력 + 서강대 미디어교육 전공 = 원래 '결과 내는/가르치는 콘텐츠' 사람. ②루센느(조회수) 이탈에도 포지션 안 바꿈 = 조회수꾼 아님. ③5-4-3-2-1 1순위 = 병원 수가 아니라 '시스템 판매'.
>
> **결정 필터 한 문장**: *"이건 시스템을 더 팔릴 자산으로 만드는가, 나를 더 노동에 묶는가?"*
> **버릴 것**: 조회수형 고객 · 시스템 없이 몸으로 때우는 일감 · 대표를 접착제로 묶는 모든 것.

## I. 종합 추론 (2차, 보정 반영) 🔎

### 사업적 목표
- 매출 5억/년(≈월 4,200만) → 3년 15억. 현재 ~1,720만/월의 **2.4배(1년)·7~8배(3년).**
- 단 **병원 수 늘리기를 가장 원치 않음** + **프리 capacity가 이미 병목(4명으로 감소)** → 15억은 산술적으로 제작 확대만으론 불가. **교육·시스템 상품 + 직계약 마진 회수**에서 나와야 함.

### 현재 상태 진단 — 급소 3개
1. **와이더뷰티 전면 종속.** 메인 고객이자 유일한 유입원이며 병원당 100만(1/3)을 가져감. 인바운드 0. → 매출·단가·고객관계가 전부 남의 손. **가장 큰 단일 리스크.**
2. **대표 = 병목이자 접착제.** 1인 대표가 시간 90%를 관리에 쓰고, 그 관리의 핵심(촬영후 핸드오프·카톡 업체관리)이 가장 큰 시간먹기이자 가장 하기 싫은 일. 프리 1명 이탈로 capacity crunch 임박.
3. **포지션-고객 미스매치.** 루센느 이탈(조회수형) → '문의 전환' 포지션과 안 맞는 고객이 섞임.

### 지금 필요한 것
1. **직계약 1건 = 즉시 +100만/월(300 full, 같은 작업).** 최고 레버리지 단일 수. 단 인바운드 0이라 **자체 유입 엔진 신설이 선결.**
2. **자체 유입 엔진**: 공개자산(1억뷰·메타/LGU+·배민 출신·강의·블로그)을 병원 마케터 타깃 인바운드 퍼널로 전환.
3. **핸드오프 시스템화**: 4명으로도 처리량 유지·증대. 이 SOP 자체가 '세팅+교육' 상품의 원료.
4. **관리·카톡 노동 위임/제거** → 대표 주 12h를 확장에 재배치.

### 확장 기회 (선호 5-4-3-2-1 + 본인 정의 반영)
- **④·⑤ 통합 = "병원 내부 미디어 세팅 + 교육" 상품화.** 본인이 직접 지목한 형태. 배민 직무교육 콘텐츠 출신 + 서강대 미디어교육 전공 + 강의 이력과 정확히 정렬. 인력 비례 아님(고마진·확장성). ⚠️ **전략적 미결: 이게 대행 매출을 잠식하나, 아니면 별도 세그먼트(대행 안 살 병원) + 대행 직계약의 프론트엔드 퍼널인가?**
- **교육 축 이미 가동 중(월 120)** → 병원 마케팅 실무 교육/코호트로 상품화 여지. 강의가 직계약 리드도 생성(급소 1·2 동시 완화).
- **전자책 재포지셔닝**: 본인 회의적 → 판매상품 X. **직계약·교육 퍼널의 리드마그넷/신뢰자산으로 격하하거나, '세팅+교육' 커리큘럼 교재로 흡수.**

### 전략 포크 — 확정 (2026-07-20)
1. **세팅+교육 = 잠식이자 프론트엔드 "둘다".** 대행 안 살 병원엔 별도 상품, 사는 병원엔 직계약 유입구. 카니발 일부는 감수.
2. **와이더뷰티 = "유지기반 + 라이벌".** 200/병원 파트너 매출은 기반으로 유지하되, 동시에 자체 직계약(full 300)을 직접 사냥 → 남의 손에 잡힌 천장을 자기 걸로. ⚠️ 관계 리스크: 대놓고 경쟁하면 기반이 흔들릴 수 있음 → 와이더뷰티가 안 건드리는 세그먼트/지역/직접문의 위주로, 그들 계정은 poach 금지.
3. **인바운드 엔진 구축에 주 12h 투입 각오함.** (전자책은 판매상품이 아니라 이 퍼널의 리드마그넷/교재로 흡수.)

## J. 실행 로드맵 — 1,720만/월 → 5억/년 (월 ~4,200만)
> 전제: 프리 4명(capacity 거의 만석) · 인바운드 0 · 와이더뷰티 기반 유지 · 대표 가용 주 12h.
> 핵심 논리: 제작은 capacity에 막혀 선형 확장 불가 → 성장은 ①직계약 마진회수 ②세팅+교육(비인력) ③교육 스케일에서 나온다.

### 4대 레버 (숫자)
- **A. 직계약 마진회수**: 직계약 병원 1곳 = 200→**300**(같은 작업, +100/월). 신규 직계약 = +300/월(+capacity 필요).
- **B. capacity 언락(핸드오프 시스템화)**: 최대 시간먹기(촬영후 넘버링·전달·카톡)를 SOP+기존 자체툴로 표준화 → 프리 안 늘리고 처리량↑ + 대표 90% 관리부담↓. **A의 전제조건.** 이 SOP가 곧 ⑤ '시스템 상품'의 원료.
- **C. 세팅+교육 상품(고티켓 1회성)**: 병원 내부 미디어 세팅+교육. 가격 미정❓(예: 500~1,000만/건). 월 1건만 해도 제작 수 곳 값. + 직계약 프론트엔드.
- **D. 교육 스케일**: 현재 120/월(1회) → 코호트·정규 출강·세팅 프로그램으로 반복화.

### 단계
- **Phase 0 (0~1개월) — 출혈 막고 토대**: 프리 이탈 전에 핸드오프 SOP화(B) · 카톡 업체관리 위임·템플릿화 · 세팅+교육 오퍼/가격 확정(C) · 직계약 오퍼페이지+리드캡처 스켈레톤 · 전자책→리드마그넷/교재 전환.
- **Phase 1 (1~3개월) — 인바운드 점화**: 공개자산(1억뷰·메타/LGU+·배민·강의·블로그)을 병원 마케터/원장 타깃 퍼널로. 강의 청중=웜리드 캡처. **첫 직계약 1~2곳(full 300)** + **첫 세팅+교육 1건.** 목표 run-rate ~2,500~3,000/월.
- **Phase 2 (3~6개월) — 비인력 축 확장**: 세팅+교육 월 1건+ 정례화 · 교육 코호트 · 직계약 2~4곳 추가 · 와이더뷰티 기반 유지. 목표 ~3,500~4,000/월 → 6개월 누적 ~2억.
- **Phase 3 (6~12개월) — 시스템 상품화(⑤)**: 표준화된 SOP+툴을 대행사/프리 대상 방법론·라이선스 or 프랜차이즈-라이트로 + 교육 스케일. 목표 ~4,200/월 = **연 5억 run-rate.**

### 리스크

# 자막 오타 검수 보조 도구

영상에 박힌(하드섭) **한국어 자막**을 OCR로 읽어 **오타 후보**를 찾아주는 팀 내부용 검수 보조 도구입니다.

## 사용법
1. 공유 비밀번호로 로그인
2. 영상 업로드 (mp4 등)
3. **고급 설정**에서 자막 위치 선택:
   - 하단 방송자막 → `하단`
   - 숏폼 본문 자막(화면 중앙) → `중앙~중하단` + 그룹핑 `text`
4. 분석 완료 후 결과표에서 **썸네일과 대조**하며 오타 확인 → 필요 시 CSV 내보내기

## 주의
- ⚠️ 이 결과는 **검수 보조용**입니다. OCR 특성상 오탐이 있을 수 있으니 반드시 사람이 썸네일로 최종 확인하세요.
- 무료 서버라 긴 영상은 처리에 시간이 걸립니다. 48시간 미사용 시 잠자기 모드가 되며 첫 접속 시 깨어나는 데 수십 초 걸립니다.
- 서버 재시작 시 진행 중이던 분석은 사라집니다. 다시 업로드하세요.

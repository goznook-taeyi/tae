## 1. 미디어교육 사업에 바로 쓰는 스킬

### wowerpoint — 문서 하나로 강의 슬라이드 PDF 생성
가장 즉효성 있는 스킬. 커리큘럼 문서, 강의 노트, 케이스 스터디를 넣으면 내러티브형 슬라이드 덱 PDF가 나옵니다.

- **강의자료**: "이 커리큘럼 문서를 wowerpoint로 만들어줘" → 수업용 덱 완성
- **클라이언트 제안서**: 제작 기획안 문서 → 프레젠테이션 PDF
- **교육 결과 보고서**: 수료 리포트를 슬라이드로 변환해 기관에 제출

### what-the — 교육생 눈높이 설명 생성
기술 개념(코덱, 렌더링, 컬러 그레이딩, AI 도구 등)을 누가·무엇을·왜·언제 구조의 쉬운 한국어로 풀어줍니다. 수업 유인물과 FAQ 제작에 활용.

### brainstorming — 커리큘럼·강좌 기획 검증
새 강좌를 열기 전 "누구를 위한, 어떤 결과를 내는 수업인가"를 질문 기반으로 검증한 뒤 설계로 넘어갑니다.

## 2. 영상 제작업에 쓰는 조합: 스킬 + 미디어 MCP 도구

이 세션에는 영상·음성·이미지 생성, 더빙, 쇼츠 스튜디오, 바이럴 예측 같은 미디어 생성 MCP 도구가 이미 연결되어 있습니다. 스킬과 조합하면:

- **기획 → 생산 파이프라인**: `brainstorming`(콘셉트 검증) → `writing-plans`(샷 리스트/작업 계획) → 미디어 MCP 도구(레퍼런스 영상·목업·더빙 생성) → `verification-before-completion`(납품 전 체크)
- **쇼츠/홍보 콘텐츠**: 쇼츠 스튜디오 + 바이럴 예측 도구로 씨사일 자체 채널·클라이언트 채널 콘텐츠 제작
- **교육 콘텐츠 제작**: 강의 내레이션 더빙, 예제 영상 생성을 수업 자료 제작에 활용

### find-skills로 영상 특화 스킬 확장
`npx skills find`로 오픈 생태계에서 ffmpeg 편집, 자막(SRT) 처리, Remotion(코드 기반 영상), 유튜브 메타데이터 워크플로우 같은 스킬을 검색·설치할 수 있습니다. 필요할 때 "ffmpeg 스킬 찾아줘"라고 요청하면 됩니다.

## 3. 대시보드·웹사이트에 쓰는 스킬

### impeccable — UI 감사와 폴리시
영상 제작사의 웹사이트는 그 자체가 포트폴리오입니다. 대시보드 리포를 세션에 추가하는 즉시:

1. `impeccable audit` — 접근성·성능·시각 위계·안티패턴 자동 감사 리포트
2. `impeccable polish` / `craft` — 발견된 문제를 실제 코드로 수정
3. `impeccable animate` / `delight` — 제작사다운 모션·인터랙션 품질로 격상

### learn-codebase / pathfinder — 기존 코드 파악
- `learn-codebase`: 리포의 소스를 전부 읽고 구조를 학습
- `pathfinder`: 기능별 플로우차트를 그리고 중복 시스템을 찾아 통합 아키텍처 제안 — 대시보드가 여러 개면 특히 유용

### superpowers — 기능 개발의 규율
- 새 기능: `brainstorming` → `writing-plans` → `test-driven-development` → `verification-before-completion`
- 버그: `systematic-debugging`이 추측 수정 대신 근본 원인부터 추적
- 외주·협업: `requesting-code-review` / `receiving-code-review`로 리뷰 품질 유지
- 마무리: `finishing-a-development-branch`로 브랜치 정리·PR·머지 체크리스트

## 4. 업무 자산화: task-observer

모든 작업 세션에서 반복 패턴을 관찰해 씨사일 전용 커스텀 스킬로 만들 기회를 포착합니다. 예상 후보:

- 영상 납품 체크리스트 스킬 (해상도·코덱·자막·썸네일 검수)
- 교육 커리큘럼 생성 스킬 (대상·차시·실습 구조 템플릿)
- 견적서/제안서 작성 스킬 (씨사일 단가·구성 반영)

새 스킬 작성 자체는 `writing-skills` 스킬이 가이드합니다.
